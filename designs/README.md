# Design demos

- `version-1/`: the chosen design (published at https://claude.ai/artifact/7VMmNVpnBEK9Ft7pYutpBq). Open `index.html` in a browser.
- `version-2/`: the alternative with giant lettering (https://claude.ai/artifact/3F57aBg4YuxsxRMJaWjZq3).
- `characters-preview/`: the redrawn characters in the style of the head illustration (https://claude.ai/artifact/EwXmy8g4gH4DqyALDbKxCN).

These files are written as artifact pages. Opened straight from disk they show without the page wrapper, which works fine in any modern browser.
The WordPress version of version 1 is in `../wordpress/`.
